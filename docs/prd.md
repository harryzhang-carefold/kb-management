# 知识库管理系统 — 产品需求文档 (PRD)

**版本**: v1.0
**开发目标**: 完全功能开发 (Production-ready)
**最后更新**: 2026-09-14

---

## 1. 产品定位

面向团队/个人的**企业级知识库管理系统**，支持多知识库、文档上传与自动解析、双路混合检索（向量 + 全文）、基于 LLM 的 RAG 问答（流式输出 + 来源引用），并提供完整的用户与权限管理。

## 2. 核心用户角色

| 角色 | 权限 |
|---|---|
| **admin** | 管理用户、创建/归档/删除任意知识库、查看系统监控、管理所有成员 |
| **user** | 创建自己的知识库、上传文档、检索、RAG 问答、管理自己是 owner 的知识库 |

## 3. 用户故事

| # | 用户故事 | 优先级 |
|---|---|---|
| US1 | 作为管理员，我能创建/编辑/归档知识库，并设置名称、描述、分块参数 | P0 |
| US2 | 作为用户，我能向知识库上传文档（PDF/DOCX/MD/TXT/HTML），系统自动解析为文本 | P0 |
| US3 | 作为用户，系统对文档智能分块，每块生成向量并建立全文索引 | P0 |
| US4 | 作为用户，我能用自然语言提问，系统混合检索相关片段，LLM 生成带引用的回答（RAG，流式） | P0 |
| US5 | 作为用户，我能管理文档：查看状态、下载原文、删除、重新解析 | P0 |
| US6 | 作为用户，我能检索：关键词搜索或语义搜索，查看命中片段 | P0 |
| US7 | 作为管理员，我能管理用户与角色，控制知识库访问权限 | P1 |

| US9 | 作为管理员，我能查看系统监控（任务队列、存储用量、索引健康） | P2 |

## 4. 功能边界

### 做（核心闭环）
- 多知识库 + 文档管理 + 异步解析管道
- 智能分块（chunk_size / overlap 可配）
- 双路索引：向量（ES dense_vector）+ 全文（ES 倒排，ik 分词）
- 混合检索（向量 kNN + BM25 + RRF 融合）
- RAG 问答（SSE 流式，带来源引用）
- JWT 认证 + RBAC（admin / user）
- 异步任务（Celery + Redis）+ 任务状态轮询
- 自动化测试（单元 + 集成）+ 部署文档

### 不做（明确排除）
- ❌ 多租户（单租户，多知识库即可）
- ❌ 在线协同编辑文档
- ❌ 语音/视频内容解析
- ❌ 知识库间联邦检索
- ❌ 图形化 RAG 编排 / Agent 工作流
- ❌ 移动端适配（桌面 Web 优先）

## 5. 非功能性需求

| 维度 | 要求 |
|---|---|
| 安全 | JWT + RBAC，SQL 注入/XSS 防护，API Key 仅存 .env，文档级权限隔离 |
| 性能 | 文档解析异步化；单次问答 P95 < 10s；检索 P95 < 500ms |
| 可靠 | 任务失败可重试（embedding 3 次指数退避），解析状态可追溯，数据持久化 |
| 可观测 | 结构化日志 + 任务队列监控 + ES/MinIO 健康检查 |
| 可扩展 | 检索引擎 / 存储 / LLM / Embedding 均可通过配置替换 |
